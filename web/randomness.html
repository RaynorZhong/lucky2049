Verifiable Randomness

One public, immutable Bitcoin block hash → reproducible, unbiased coin flips and dice rolls, computed in your browser (its own SHA-256/HMAC, no server). The same machinery that picks the lottery numbers — anyone with the hash gets the exact same outcomes.

This is a demonstration, not a game. No betting, no money, no stakes — just a transparent example of public, verifiable randomness from the Bitcoin chain.

How each result is derived (recompute it yourself)

seed = SHA-256(hash). A byte stream is HMAC-SHA-256(seed, "coin:i") / "dice:i" for i = 0, 1, 2, … Coin flip j = bit j of the coin stream (MSB-first), 1 → Heads, 0 → Tails — a fair bit. Die = the next byte b of the dice stream with b < 252, value b mod 6 + 1 (bytes 252–255 are rejected so all six faces stay equally likely — no modulo bias). Full spec: docs/RANDOMNESS.md ↗.
