Economic-security bound

Why the draw is safe against manipulation, in live numbers. Only the miner of a window's last block can re-roll the result, and each re-roll forfeits a whole block reward B — so grinding never pays unless a single prize tops B / p. lucky2049 runs no prize pool; this is simply the ceiling any downstream prize must stay under to keep the beacon economically secure.
